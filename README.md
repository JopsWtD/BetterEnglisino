# Class Roulette

Student draw (wheel or poker cards) and five casino games for English class: European roulette, slot machine, reaction, higher or lower, and blackjack.

## Run it on your computer
Double-click `index.html` (Chrome, Edge or Firefox). Nothing to install.

## Publish it on GitHub Pages
1. Create a repository and upload this folder as it is (`index.html`, `css/`, `js/`).
2. In the repository: **Settings → Pages → Build and deployment → Deploy from a branch**, branch `main`, folder `/ (root)`.
3. After a minute or two it will be live at `https://YOUR-USER.github.io/REPO-NAME/`.

## Question bank
Open the **Questions** tab to add questions (Fill the blank, Multiple choice, Fix the error, Theory), one at a time or many at once with this format:

```
FB: She ___ to school every day. | goes
MC: Past simple of "buy"? | *bought | buyed | buys
FE: He don't like pizza. | He doesn't like pizza.
TH: When do we use the present perfect? | Optional answer
```

## Notes
- The student list and the questions are saved in each computer's browser (localStorage).
- Fonts load from Google Fonts; without internet a system font is used.
